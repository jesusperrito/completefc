# Complete FC · Brand foundations

Single page brand foundations site for Complete FC. Master V2, issued 02.08.2026.

## Deploy on GitHub Pages
1. Push this folder to a repository.
2. In the repo settings, open Pages and set the source to the main branch, root folder.
3. The site serves from index.html. No build step required.

## Structure
- index.html · the full document, all marks inline as recolourable SVG symbols
- assets/img · photography and plate imagery
- assets/marks · the final identity vectors as standalone files

## Notes
- Marks can also be downloaded from the site itself, in the Commission 001 section, as SVG or hi res transparent PNG.
- Fonts load from Google Fonts and require an internet connection.
